# 📋 Пошаговая инструкция установки (Вариант 1 - Готовый .exe)

## Самый простой способ - используем готовый файл

### ШАГ 1️⃣: Скачивание файла

1. Перейдите в репозиторий: https://github.com/damirkamaev-eng/invoice_generator_desktop
2. Нажмите на кнопку **"Code"** (зеленая кнопка справа вверху)
3. Выберите **"Download ZIP"**
4. Дождитесь загрузки файла `invoice_generator_desktop-main.zip`

**Или скачайте готовый .exe напрямую из папки `dist/`** (если уже собран)

---

### ШАГ 2️⃣: Распаковка архива

1. Найдите скачанный файл `invoice_generator_desktop-main.zip`
2. Нажмите правой кнопкой мыши → **"Извлечь все..."**
3. Выберите папку для распаковки (например, `C:\Program Files\invoice_generator` или `D:\Program Files\`)
4. Дождитесь завершения распаковки

---

### ШАГ 3️⃣: Сборка .exe (первый раз)

⚠️ **ВАЖНО:** Если вы скачали исходный код, нужно собрать .exe

#### Вариант 3а: Автоматическая сборка (просто и быстро)

1. Откройте папку `invoice_generator_desktop-main`
2. Найдите файл `build.bat`
3. **Дважды щелкните** по нему
4. Откроется черное окно (командная строка)
5. Подождите... процесс может занять 2-5 минут
6. Когда появится сообщение **"Готово! Файл: dist\\invoice_generator.exe"** - закройте окно

#### Вариант 3б: Если build.bat не сработал

1. Нажмите **Win + R**
2. Введите `cmd` и нажмите Enter
3. В черном окне введите по очереди:

```bash
cd C:\Users\ВашеИмя\Downloads\invoice_generator_desktop-main
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --onefile --windowed --name invoice_generator main.py
```

---

### ШАГ 4️⃣: Запуск программы

**Способ 1: Прямой запуск из папки dist**

1. Откройте папку `invoice_generator_desktop-main`
2. Откройте папку `dist`
3. Найдите файл `invoice_generator.exe` (с иконкой приложения)
4. **Дважды щелкните** по нему
5. **Готово!** Программа запущена

**Способ 2: Создайте ярлык на рабочем столе**

1. Найдите `invoice_generator.exe` в папке `dist`
2. Нажмите правой кнопкой мыши → **"Отправить"** → **"Рабочий стол (создать ярлык)"**
3. Теперь вы можете запускать программу двойным щелчком с рабочего стола

**Способ 3: Скопировать как портативную версию**

1. Скопируйте файл `invoice_generator.exe` в удобное место
   - Например: `C:\Invoice_Generator\`
   - Или: `D:\Мои документы\Invoice_Generator\`
2. Запустите его оттуда
3. Папка `data/` (с базой данных) создастся автоматически рядом с .exe

## 🎯 Первый запуск программы

### Что вы увидите:

1. **Главное окно** с тремя вкладками:
   - 📄 **Создать документ** - создание счетов и актов
   - 👥 **Заказчики** - управление базой данных заказчиков
   - 📋 **История** - все созданные документы

### Первые шаги:

#### 1. Добавьте заказчика

1. Перейдите на вкладку **"👥 Заказчики"**
2. Заполните форму:
   - **Название организации** (требуется) - например: ООО "Компания"
   - **ИНН** - 10 или 12 цифр
   - **Расчетный счет** - 20 цифр
   - **БИК** - 9 цифр
   - **Юридический адрес** - полный адрес
3. Нажмите **"Добавить заказчика"**
4. Если данные верны, увидите сообщение **"Заказчик добавлен"**
5. Новый заказчик появится в таблице снизу

#### 2. Создайте первый документ

1. Перейдите на вкладку **"📄 Создать документ"**
2. Заполните форму:
   - **Тип документа**: выберите "Счет на оплату" или "Акт выполненных работ"
   - **Номер документа**: например, "1", "2", "100" и т.д.
   - **Дата документа**: автоматически установлена на сегодня
   - **Заказчик**: выберите из выпадающего списка
   - **Маршрут**: например, "Казань - Екатеринбург"
   - **Дата начала**: например, "05.09.2024"
   - **Дата окончания**: например, "08.09.2024"
   - **Сумма**: введите цифры (например, 145000)
   - **Добавить НДС**: отметьте, если нужно
   - **Ставка НДС**: 18% (по умолчанию)
3. Нажмите **"Сохранить документ"**
4. Документ сохранится в базе данных

#### 3. Посмотрите историю

1. Перейдите на вкладку **"📋 История"**
2. Вы увидите все созданные документы
3. Нажмите **"Обновить"**, чтобы обновить список

## 💾 Где хранятся данные?

**Все ваши данные хранятся в одной папке `data/`**

- Расположение: рядом с файлом `invoice_generator.exe`
- Файл БД: `invoice_generator.db`

### Как сделать резервную копию:

1. Найдите папку `data/` рядом с .exe
2. Скопируйте её в безопасное место (например, на флешку или облако)
3. Если что-то случится, просто скопируйте папку обратно

### Как перенести на другой компьютер:

1. Скопируйте два файла/папки:
   - `invoice_generator.exe`
   - `data/` (папка)
2. Поместите их в одну папку на другом компьютере
3. Запустите .exe - все ваши данные будут там!

## ⚠️ Часто возникающие проблемы

### Проблема: "Программа не запускается"

**Решение:**
1. Убедитесь, что на компьютере установлена Windows 7 или выше
2. Проверьте, что файл находится в папке, где вы можете читать/писать
3. Попробуйте запустить от администратора (правый клик → "Запустить от администратора")

### Проблема: "Ошибка при запуске build.bat"

**Решение:**
1. Убедитесь, что Python установлен (откройте cmd и введите `python --version`)
2. Python должен быть добавлен в PATH (отметьте это при установке)
3. Следуйте Варианту 3б (ручная сборка)

### Проблема: "База данных недоступна"

**Решение:**
1. Закройте программу
2. Найдите папку `data/` рядом с .exe
3. Если файл `invoice_generator.db` повреждена, удалите её
4. Запустите программу заново - БД создастся автоматически

### Проблема: "Не видны добавленные заказчики в документе"

**Решение:**
1. Закройте вкладку "Создать документ"
2. Откройте её снова
3. Список должен обновиться
