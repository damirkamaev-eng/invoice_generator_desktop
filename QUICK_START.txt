  БЫСТРЫЙ СТАРТ - Invoice Generator Desktop
════════════════════════════════════════════════════════════════

🚀 ЗАПУСК В 3 ШАГА:

1. Найдите папку: invoice_generator_desktop-main
   
2. Откройте файл: build.bat
   (Дважды щелчок по файлу)
   
3. Подождите 2-5 минут пока программа будет собрана

✅ Готово! Файл для запуска:
   invoice_generator_desktop-main → dist → invoice_generator.exe

════════════════════════════════════════════════════════════════

🎯 ПЕРВЫЙ ЗАПУСК:

1. Двойной щелчок по invoice_generator.exe
   
2. Перейдите на вкладку "👥 Заказчики"
   
3. Добавьте первого заказчика (название обязательно)
   
4. Перейдите на вкладку "📄 Создать документ"
   
5. Заполните форму и нажмите "Сохранить документ"
   
6. Смотрите историю на вкладке "📋 История"

════════════════════════════════════════════════════════════════

📁 ВАШ ДАННЫЕ ХРАНЯТСЯ ЗДЕСЬ:

   Папка: data/
   Файл: invoice_generator.db
   Расположение: рядом с файлом invoice_generator.exe

💾 РЕЗЕРВНАЯ КОПИЯ:
   Просто скопируйте папку data/ в безопасное место

🔄 ПЕРЕНОС НА ДРУГОЙ ПК:
   Скопируйте оба:
   - invoice_generator.exe
   - папка data/
   
   И запустите на другом компьютере!

════════════════════════════════════════════════════════════════

❓ ПРОБЛЕМЫ?

• Программа не запускается?
  → Скачайте Python с python.org
  → Отметьте "Add Python to PATH"
  → Запустите build.bat еще раз

• Нет заказчиков в списке документов?
  → Закройте и откройте заново вкладку

• База данных испорчена?
  → Удалите файл invoice_generator.db
  → Запустите программу - она создастся заново
